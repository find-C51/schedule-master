# 日程智排 — AI 每日时间规划智能体

> 🏆 首届「中国移动杯」人工智能创新大赛 · 智能体开发赛道

**把大目标拆成每天小任务，自动排进课表里。前晚花 1 分钟，第二天不慌乱。**

这是一个**离线优先**的 PWA：智能排程引擎完全跑在浏览器里，数据存在手机本地，装到主屏幕后**不需要网络、不需要电脑**也能用。

## ✨ 功能

- 🧡 **小暖助手** — 像人一样对话：你说「明天8点到10点上课，下午去图书馆」，她听懂并帮你排好；你喊累，她也会安慰你
- 🗣️ **自然语言排程** — 一句话识别多个时间段、时长、固定/灵活/保护任务
- 🎯 **四层目标拆解** — 大目标 → 长期 → 中期 → 每日小任务（内置 14 类模板：考研/考公/论文/考证/减肥/编程…）
- ⚠️ **突发情况调整** — 突发任务自动/选择/手动三种处理
- 🎨 **四种交互模式** — 表格 / 效率 / 暖心 / 趣味
- 🛡 **保护时间** — 三餐、午休、睡眠不可被占用
- 📊 **进度追踪** — 完成率、连续天数、目标进度条
- 📱 **离线 PWA** — 安装到主屏幕，完全离线运行

## 🚀 立即使用

线上地址（GitHub Pages，需 HTTPS 才能离线安装）：

```
https://find-C51.github.io/schedule-master/
```

手机打开 → 浏览器菜单 → **「添加到主屏幕」**，之后即可当 App 离线使用。

## 🛠 技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS |
| 排程引擎 | 浏览器内运行（意图解析 + 贪心排程 + 目标拆解 + 冲突解决）|
| 数据 | localStorage（离线本地存储）|
| PWA | vite-plugin-pwa（离线缓存 + 可安装）|
| 语音 | 浏览器 Web Speech API（需 HTTPS）|

> `backend/` 为历史 FastAPI + SQLite 版本（供参考 / 后续上云多用户版使用）。离线版不依赖它。

## 🧑‍💻 本地开发

```bash
cd frontend
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 构建到 frontend/dist
```

预览构建产物：

```bash
npm run preview
```

## 📂 项目结构

```
schedule-agent/
├── frontend/
│   └── src/
│       ├── engine/        # 离线引擎（意图解析/排程/目标拆解/小暖助手）
│       ├── store/db.ts    # localStorage 数据层
│       ├── services/api.ts# 本地数据接口（替代后端）
│       └── pages/         # 今日/排程/目标/进度/设置/小暖
└── backend/               # 历史 FastAPI 版本（参考）
```
